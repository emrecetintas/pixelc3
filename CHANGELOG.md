# Changelog

## 0.4.3

- Rename the Blender add-on to **PixelC3**. Existing Blender projects and saved styles retain their settings.
- Use `pixelc3` in new installer and PNG export filenames.

## 0.4.2

- Prepare the standalone Blender add-on and procedural examples for public distribution.
- Replace the novelty dithering tile with **Diamond Tile**. Saved styles still load the same dither slot and use the diamond pattern when regenerated.

## 0.4.1

- Detect missing external sources in the sidebar.
- Relink a moved source while preserving its look, result and material references.
- Export the packed PNG directly from the project.
